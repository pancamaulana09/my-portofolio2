# Selected Work Narrative Mapping

The new reference is a continuous horizontal editorial narrative rather than a conventional project-card carousel. Its key layout roles are: a branded introduction panel; a narrow vertical system strip; paired media panels; an oversized statement panel; a contextual project/approach panel; a focused identity panel; additional media; and a concluding feature panel.

The replacement will retain the portfolio’s own design system—ink, paper, signal blue, Helvetica Neue, and Courier Prime—and source all content from the existing portfolio data.

| Narrative role | Portfolio adaptation |
| --- | --- |
| Intro panel | “Selected Work” framing the projects as shipped systems and practical experiments. |
| Vertical system strip | “Concept → interface → build → deploy.” |
| Paired media | IoT Hydroponic System and PT Cipta Karya Pertiwi Trans imagery. |
| Statement panel | “Built for the real world.” |
| Context panel | A short first-person explanation of end-to-end work across design and engineering. |
| Focus panel | “Systems, in motion.” |
| Closing feature | Gowes / Fenomena Bike with a project-focused CTA. |

Desktop will use vertical scroll to scrub a pinned horizontal track. Mobile and reduced-motion modes will use normal stacked panels with no pinned interaction.
